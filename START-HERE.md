# Start here

**[Open the illustrated PDF guide](Documentation/Automatic-Printer-Deployment-Guide.pdf)**

1. Review the [safety precautions](README.md#safety-precautions). Identify an approved pilot user, client and printer.
2. Prepare the server queue and confirm an authorized test account can print.
3. Create the department groups and a user-targeted Shared Printer preference. Link the GPO to the appropriate user OU.
4. Sign in as the pilot user, verify the connection and print. Enable removal of the old connection only after pilot approval.
5. Follow the rollback steps in the guide if the new queue fails.

The guide uses fictional infrastructure and recreated console views. The live deployment and rollback were not independently lab-tested.
